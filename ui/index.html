Epic 使用系统默认浏览器完成首次授权，不会自动反复打开验证窗口。Steam 使用独立登录窗口。请直接在平台页面登录；助手不保存账号密码。

Epic · Chrome 自动结账

正在读取

接口要求网页结账时，连接器会在已登录 Epic 的 Chrome 中打开后台标签页完成零元领取。保持 Chrome 运行；人机验证或账号异常时暂停该游戏并提醒。

首次安装 Chrome 连接器
  1. 在刚才登录 Epic 的 Chrome 中打开 chrome://extensions/。
  2. 启用“开发者模式”，点击“加载已解压的扩展程序”。
  3. 选择下方目录。安装后面板会显示“已连接 Chrome”。
